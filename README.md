---

## 🛠️ Excel Tools & Features Used

- **Data Modeling & PivotTables:** Structured raw dataset using Pivot Tables for dynamic calculations.
- **Dynamic Slicers & Timeline Filters:** Interactive regional filters (*Alex, Cairo, Canal, Delta, Giza, Sainai, Upper Egypt*) and monthly controls (*Jan–Dec*).
- **Custom Visual Formatting & UI:** High-contrast corporate UI theme, rounded metric KPI cards, custom donut and bar charts, and smooth sheet navigation.
- **Formulas & Measures:** Utilized Excel functions (`SUMIFS`, `GETPIVOTDATA`, conditional formatting rules) for custom KPI metric rings.
